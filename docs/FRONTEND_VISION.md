# Frontend Vision

## Goal

CostPilot should feel like a real startup product that could launch on Product Hunt tomorrow.

The UI must communicate:
- trust
- technical sophistication
- premium quality
- financial clarity
- modern SaaS aesthetics

The experience should feel closer to:
- Linear
- Vercel
- Raycast
- Stripe
- modern AI products

with subtle inspiration from cinematic agency sites like Digital Heroes.

---

# Design Direction

The frontend should NOT look like:
- an admin dashboard template
- a college assignment
- a generic Tailwind landing page
- a crypto casino website
- an over-animated WebGL experiment

The frontend SHOULD look:
- polished
- cinematic
- modern
- smooth
- responsive
- screenshot-worthy

---

# Animation Philosophy

Animations are allowed and encouraged IF they improve perceived quality.

Animations should:
- feel intentional
- support visual hierarchy
- improve engagement
- improve perceived polish

Animations should NOT:
- distract from the audit results
- reduce readability
- hurt performance
- feel gimmicky

---

# Motion Guidelines

Use:
- Framer Motion
- subtle transforms
- opacity reveals
- smooth hover transitions
- cursor lighting effects
- animated gradients
- subtle parallax
- spotlight hover interactions

Avoid:
- excessive spinning 3D scenes
- heavy particle systems
- chaotic transitions
- unnecessary infinite animations
- GPU-heavy effects on every section

---

# Three.js Usage

Three.js should be used selectively.

Allowed use cases:
- floating orb
- subtle AI sphere
- hero background enhancement
- ambient lighting effects

Do NOT:
- build the whole app in 3D
- use fullscreen heavy WebGL scenes
- compromise Lighthouse scores

Performance matters.

---

# Most Important Screen

The audit results page is the most important experience in the product.

It must:
- feel premium
- communicate savings instantly
- look shareable
- feel trustworthy
- present recommendations clearly

This is the screen users will:
- screenshot
- share
- evaluate credibility from

Most frontend effort should go into:
1. Results page
2. Landing page hero
3. Audit form UX

---

# UI Style

Preferred:
- dark modern UI
- restrained gradients
- strong typography
- soft glows
- depth layering
- premium spacing
- large readable numbers
- subtle glass effects

Avoid:
- visual clutter
- excessive blur
- rainbow gradients
- low-contrast text
- tiny typography

---

# Cursor Interaction

Subtle cursor-reactive effects are encouraged.

Examples:
- spotlight hover cards
- radial glow following cursor
- hover lighting
- soft background response

These effects should:
- feel smooth
- remain subtle
- not interfere with usability

---

# Performance Requirements

Even with animations:
- Lighthouse performance >= 85
- animations must remain smooth
- mobile performance is mandatory

Optimize:
- lazy loading
- animation frequency
- image sizes
- unnecessary re-renders

---

# Engineering Priority

Priority order:
1. Functionality
2. Reliability
3. UX clarity
4. Performance
5. Visual polish
6. Experimental effects

Never sacrifice product usability for visuals.

---

# Development Phases

## Phase 1
Build:
- layout
- typography
- sections
- responsive structure
- audit UX

WITHOUT advanced animations.

---

## Phase 2
Add:
- motion polish
- hover interactions
- transitions
- spotlight effects
- animated numbers

---

## Phase 3
ONLY if time remains:
- Three.js enhancements
- ambient background effects
- advanced cinematic polish

---

# Final Product Goal

The final frontend should feel like:
"A real funded startup product."

Not:
"A frontend animation demo."
