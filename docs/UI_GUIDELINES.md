# UI Guidelines

## Overall Feel

CostPilot should feel:
- premium
- modern
- clean
- trustworthy
- launch-ready

The interface should resemble:
- modern SaaS landing pages
- developer tools
- startup products

---

# Visual Direction

Focus on:
- strong typography
- spacing consistency
- visual hierarchy
- readability
- clean layouts

Avoid:
- clutter
- excessive decoration
- heavy gradients everywhere
- noisy dashboards

---

# Layout Philosophy

Prefer:
- whitespace
- breathing room
- readable sections
- simple grids

Avoid:
- cramped layouts
- overly dense interfaces

---

# Results Page Importance

The audit results page is the most important screen.

It should:
- clearly communicate savings
- feel screenshot-worthy
- emphasize trust
- present recommendations clearly

---

# Mobile Experience

The product must work well on:
- mobile
- tablets
- desktop

Mobile usability is mandatory.

---

# Color Philosophy

Use a restrained palette.

Prioritize:
- readability
- contrast
- professionalism

---

# Animation Philosophy

Animations should:
- feel subtle
- improve clarity
- never distract

Avoid:
- excessive motion
- flashy transitions
- unnecessary animation

---

# Component Philosophy

Prefer:
- reusable UI primitives
- consistency
- simple interfaces

Avoid:
- over-customized components
- inconsistent interaction patterns
