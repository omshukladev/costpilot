# CostPilot — Project Overview

## What Is CostPilot?

CostPilot is a SaaS web application that audits AI tooling spend for startups and engineering teams.

Users enter:
- AI tools
- subscription plans
- monthly spend
- team size
- primary use case

The application analyzes spending patterns and generates:
- optimization recommendations
- downgrade suggestions
- alternative tooling recommendations
- estimated savings
- AI-generated summaries

---

# Primary Goals

- Build a believable startup MVP
- Create trustworthy audit recommendations
- Deliver polished UX
- Produce shareable audit reports
- Generate high-quality engineering documentation

---

# Core Product Principles

The application should feel:
- modern
- trustworthy
- startup-grade
- launch-ready

Avoid:
- unnecessary complexity
- overengineering
- enterprise-style architecture
- feature bloat

---

# Core User Flow

1. User lands on homepage
2. User enters AI tooling information
3. Audit engine analyzes spend
4. Results page displays recommendations
5. AI summary is generated
6. User optionally submits email
7. User can share public report URL

---

# Important Constraints

- No authentication required for MVP
- Email capture occurs AFTER value delivery
- Audit logic must be deterministic
- AI is only used for personalized summaries
- Public reports must not expose sensitive information
