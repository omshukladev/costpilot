# State Management

## Client State

Use Zustand for:
- audit form state
- UI state
- lightweight client state

Avoid excessive global state.

# Server State

- API requests
- caching
- loading states
- retries

# Form State

# Important Principle

Keep state:
- localized
- predictable
- minimal
